# Product Management System

A simple CRUD application built using React, Node.js, Express.js and MySQL.

## Features

- Add Product
- View Products
- Update Product
- Delete Product
- Form Validation

## Tech Stack

- React.js
- Node.js
- Express.js
- MySQL
- React Query
- Tailwind CSS

## Run Project

### Backend

```bash
cd server
npm install
npm run dev
